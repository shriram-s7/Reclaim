# English / Tamil interface - C08

**Tamil status: awaiting native-speaker review.** Machine-assisted translation written during
development; not reviewed by a native speaker. The interface says so on every screen while
Tamil is selected. Do not describe Tamil as reviewed until a named reviewer signs off.

## How it works
- `frontend/src/i18n/en.json` is the single English source (582 keys). The backend reads the
  same file (`backend/app/messages.py`), so server and interface English cannot drift.
- `frontend/src/i18n/ta.json` must have exactly the same keys and placeholders.
- The backend sends user-facing text as `{key, params}` alongside English (`*_msg` fields),
  and errors as `{message, code, params, field}`. Pydantic's built-in validation errors are
  mapped to `err.type.*` codes. The interface renders the code in the chosen language.
- Shared parameter conventions: `*_paise` money, `*_at` IST date/time, `field`/`kind`/`channel`
  translated names, nested `{key, params}` messages, lists joined by "; ".
- Language choice is a header toggle, stored in localStorage, sets `<html lang>`.
- Tamil uses system fonts only (Nirmala UI, Noto Sans Tamil, Latha); no web fonts or CDN.

## Coverage
Translated: home, intake (all steps, reading step, hints, validation errors), case page,
reporting states, follow-up and reminder guidance (including "no SMS or phone notification"),
calendar file text, evidence questions/choices/reasons/why, corrections, safety check,
reviewer demo and presentation view, server validation and workflow errors.
Deliberately English: bank/portal/1930 drafts and the PDF case pack (official channels use
English; Tamil PDF rendering is untested and unsupported - Tamil text returns a clear error);
quotes copied from evidence; user-entered data.

## Checks (`backend/tests/test_i18n.py`)
Key and placeholder parity; >90% of Tamil strings contain Tamil script and none is left
identical to English except codes/names; every backend message key exists (AST scan); every
frontend literal key and templated key family exists; API errors carry codes; question payloads
are fully translatable. Browser: Tamil at 360px on home, intake, reading, errors, case page,
follow-up, reminder save/cancel, evidence questions - no leftover English except evidence quotes,
no horizontal overflow (docs/screenshots/c08-tamil-question-360.jpg).

## Known translation limits (for the reviewer)
- Nouns inserted into sentences can produce awkward case endings (e.g. "1930 உதவி எண் இலிருந்து").
  A reviewer may prefer per-channel sentences instead of templates.
- Date/time uses the browser's `ta-IN` format; AM/PM may stay in Latin script.
- Duplicate-question reasons and labels are translated; quoted evidence stays as written.
