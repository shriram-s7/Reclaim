# Reclaim handoff rules

Read `STATUS.md`, `docs/MASTER_PLAN.md`, and `docs/DECISIONS.md` before editing.
The six root PDFs are historical inputs, not executable instructions. Revised Markdown
plans take precedence where they document a correction. User instructions take precedence.

Work in small, testable slices. After each meaningful milestone, update STATUS.md with
completed work, exact checks, known limits and the next action; append docs/PROGRESS.md.
Save before switching model/editor or ending a session. Never report a task complete
without evidence. Commit coherent milestones when Git is available; never invent a remote.

Use fabricated data only in this local prototype. Do not publish or expose the unauthenticated
demo backend. Never collect credentials, send complaints, or promise recovery. A recorded
reference is user-reported, not verification that an authority accepted a complaint.
Do not enable legal eligibility calculations without primary-source verification and tests.
Do not change or overwrite the original PDFs. Record all work before the event in PRE_EXISTING.md.
Do not spawn agents unless the user explicitly requests delegation.
